## Adaptive learning (rules in `LearnerModel`, inspectable)

- **Strong understanding:** a Secure topic (2 distinct unassisted correct) gets one **Application** item in a new situation ("Challenge · apply it") instead of more of the same; a solved challenge is not repeated. 8 new items, one per topic.
- **Reduce repetition:** after a first-try correct answer, a follow-up at the same or a lower level is skipped.
- **Partial understanding:** rebuilding the journey acknowledges the stages already in the right order before guiding the next link.
- Existing tiers kept: attention hint → comparison + assisted retry + "Show me" worked demonstration → answer + "needs practice".
- No "Try it / Skip" gate before checks: the first question shows directly; **Skip** skips the whole check.
- Correct/incorrect answers now have restrained confirm/deny sounds.

## Ask Niko (local curated, still not generative)

"What should I do now? / hint / stuck" answers from live state: the current objective plus the simulation's actual readout (e.g. "…Light meets behind the retina → make the lens more curved."). With a question open it gives the first attention hint only, never the answer. "Near / far" requests in the focus challenge move the object but never focus the lens for the learner.
