## Lessons / gotchas
- `SkinnedMeshRenderer.bounds` is stale in edit mode, so bake meshes to measure (Builder.TrueBounds).
- Z-Anatomy registration needs full-frame alignment (forward + left/right axis); two-point alignment can flip.
- Never merge sub-meshes across different texture atlases. FitnessMan's body atlas leaked onto the shirt, so the figure is now untextured.
- `WaitForEndOfFrame` never fires in batch mode; the autopilot uses frame yields + `Camera.Render` there.
- The prototype's `AssetAudit` blocks non-development builds, so `PlayerBuilds` makes Development builds unless `-heRelease` is passed.
- Ghosting the interior of a *closed* eye lets the background show through the pupil, so isolation keeps interior parts solid until the cutaway.
- Glass with a bright albedo turns milky because both faces are lit; a dark albedo plus spec/env reflection reads as clear.
- Uniform decimation of Z-Anatomy crushed the low-poly cerebral lobes. Decimate only the dense deep structures.
- Another Claude Code process's startup cleanup can wipe this session's scratchpad. Keep run scripts under `Logs/` (git-ignored).
